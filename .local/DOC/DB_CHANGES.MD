# Database Changes Log

A chronological record of every change made to the WordPress sandbox database
through the dashboard. **Oldest entries first; add new entries at the bottom.**
Never rewrite or reorder existing entries.

Format for each entry:

## YYYY-MM-DD HH:MM — Short summary

- **Area:** e.g. Posts, Pages, Settings, Plugins, Themes, Menus, Widgets, Users
- **Change:** what was added, edited, or deleted
- **Details:** object IDs, titles, slugs, or option names affected
